# ドキュメントの更新

このページでは、[Adobe Experience League](https://experienceleague.adobe.com/en/docs/commerce)および[Adobe Developer](https://developer.adobe.com/commerce/docs/)に関するAdobe Commerce テクニカルドキュメントの更新情報を示します。 これらのリストを使用して、読者のフィードバックに応じて作成された新しいトピック、修正されたガイダンス、改善を見つけることができます。

フィードバック主導の変更では、不明確な指示、詳細の欠落、不正確な情報など、読者によって提起された提案や問題に対処します。 例えば、フィードバックにより、[製品レコメンデーションのドキュメント ](https://experienceleague.adobe.com/en/docs/commerce/product-recommendations/boundaries-limits)で、バンドルおよびグループ化された製品のサポートに関する修正が行われました。

## フィードバックの提供

フィードバックは、ドキュメントの改善に役立ちます。 次の方法で貢献することができます。

* Adobe Experience Leagueでは、右側のサイドバーまたは狭い画面のページ下部にあるフィードバック領域を使用します。 「サムズアップ」ボタンまたは「サムズダウン」ボタンをクリックして、トピックを評価し、オプションのコメントフィールドを表示します。 コメントを残すには、フィードバックを入力し、**[!UICONTROL Submit]**&#x200B;をクリックします。 問題の報告と編集の提案について詳しくは、[Adobe Docs Contributor Guide on Adobe Experience League](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction)を参照してください。
* Adobe Developerでは、トピックからリンクされたパブリック GitHub リポジトリを使用して、ドキュメントの問題を報告するか、編集を提案します。 手順については、[Adobe Developerのドキュメントへの投稿](https://developer.adobe.com/commerce/contributor/guides/doc-contributions/)を参照してください。

トピック URLを含め、不明確な点、欠けている点、正しくない点を説明することで、ドキュメントチームが提案を理解できるようにします。
