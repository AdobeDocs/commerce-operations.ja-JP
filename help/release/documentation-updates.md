# ドキュメントの更新

このページでは、[Adobe Developer](https://experienceleague.adobe.com/en/docs/commerce)および[Experience League](https://developer.adobe.com/commerce/docs/)に関するAdobe Commerce テクニカルドキュメントの更新情報をまとめます。 これらのリストを使用して、読者のフィードバックに応じて作成された新しいトピック、修正されたガイダンス、改善を見つけることができます。

フィードバック主導の変更では、不明確な指示、詳細の欠落、不正確な情報など、読者によって提起された提案や問題に対処します。 例えば、フィードバックにより、[製品レコメンデーションのドキュメント ](https://experienceleague.adobe.com/en/docs/commerce/product-recommendations/boundaries-limits)で、バンドルおよびグループ化された製品のサポートに関する修正が行われました。

## フィードバックの提供

フィードバックは、ドキュメントの改善に役立ちます。 次の方法で貢献することができます。

* Experience Leagueでは、トピックの下部にあるフィードバックエリアを使用して、その有用性を評価し、コメントを残します。 問題の報告と編集の提案について詳しくは、[Adobe Docs Contributor Guide](https://experienceleague.adobe.com/en/docs/contributor/contributor-guide/introduction)を参照してください。
* Adobe Developerでは、トピックからリンクされたパブリック GitHub リポジトリを使用して、ドキュメントの問題を報告したり、編集を提案したりします。

トピック URLを含め、不明確な点、欠けている点、正しくない点を説明することで、ドキュメントチームが提案を理解できるようにします。
