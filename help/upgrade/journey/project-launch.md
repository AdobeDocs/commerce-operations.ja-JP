# プロジェクトの立ち上げ

健全なe コマースサイトを維持することは、最初のリリースと同様にビジネスの成功に不可欠です。その重要な側面は、サイトを可能な限りスムーズに運営できるように、積極的に計画とアップグレードの準備を行うことです。

この期間に適切なアップグレードの期待値を設定しないと、将来の不満につながります。 このガイドでは、[&#x200B; リリースの頻度](/help/release/schedule.md)を理解し、アップグレードを計画する方法とタイミングを定義するのに役立ちます。
