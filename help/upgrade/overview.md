# アップグレードプロセスの概要

Adobe Commerceプロジェクトをアップグレードすることは、オンラインストアの安全性とPCI認定を維持し、ピーク時の効率性を維持するために不可欠です。 このガイドでは、アップグレードを準備する際の重要な考慮事項について説明します。

このガイドでは、Adobe Commerceの一般的なアップグレードジャーニーの概要と、そのジャーニーに従うべきベストプラクティスについて説明します。 また、アップグレードプロセスの技術的な詳細について、タイムリーな例と、最新バージョンのAdobe Commerceにアップグレードするための手順ごとの手順を示します。 Adobe Commerce [&#x200B; リリーススケジュール &#x200B;](../release/schedule.md)を確認し、早期にアップグレードの準備を開始することが重要です。 Adobeでは、毎年リリーススケジュールを公開して販売者の計画プロセスを促進し、各パッチリリースサイクルをアップグレードすることをお勧めします。 PCIに準拠するためには、最新のパッチやセキュリティパッチを適用する必要があります。

## このガイドは誰のためのものでしょうか？

このガイドのターゲットオーディエンスは次のとおりです。

- **コマース マネージャーとテクニカル ディレクター** - アップグレード ジャーニー、定期的なアップグレードの重要性、アップグレードの最適な計画と準備の方法について理解します。
- **運用および開発チーム** - Adobe Commerceの最新バージョンにアップグレードするために必要な技術的な手順と、プロセスを容易かつ迅速に、手頃な価格で利用できるツールについて説明します。

## アップグレードプロセスの説明

Adobe Commerceを選択した理由のひとつに、次のようなものがあります。

- すぐに利用できる広範な機能セット
- コアコードとは別に提供されるSaaS機能
- Marketplace拡張機能の堅牢な提供
- ビジネスや顧客のニーズに最適に対応できるようにサイトをカスタマイズできる、無限の柔軟性を実現する独自の機能

しかし、拡張性が高くカスタマイズ可能な製品であることの利点は、カスタマイズがベストプラクティスにコーディングされていない場合、潜在的なアップグレードの問題を引き起こす可能性があり、予想以上のアップグレードコストがかかります。

_では…なぜアップグレードするのでしょうか？_

アップグレードすることで、変化の激しいデジタルコマース業界において、俊敏に行動し、売上とコンバージョンを最大化するAdobe Commerceの最新機能とプラットフォームの互換性を確保できます。 定期的なメンテナンスプランにアップグレードを含めることは、ストアの安全性とPCI認定を維持し、ピーク時の効率を維持するために不可欠です。

### セキュリティ

セキュリティインシデントの83%が古いソフトウェアで発生するため、セキュリティはアップグレードの主な理由の1つです。 [IBM](https://www.ibm.com/reports/data-breach)によると、データ侵害の平均コストは386万ドルで、アップグレードによってこのリスクを軽減するコストよりもはるかに大きくなります。 Adobeでは、年間を通じてオンラインストアの安全性を確保するための2つの方法をご用意しています。

- **パッチリリース** - セキュリティ、パフォーマンス、品質、優先度の高いバグ修正を含めます。
- **セキュリティパッチリリース**：サイトを安全に保ち、実装しやすくするための修正と機能強化を含めます。

Adobe Commerce Cloud バージョン 2.4.4から2.4.9を使用している場合は、環境を安全かつコンプライアンスに保つために必要なアクションと期限について、[&#x200B; セキュリティとコンプライアンスに関する通知](../release/security-enforcement-policy.md)を参照してください。

### パフォーマンス

パフォーマンスも、アップグレードの主な理由です。 [HubSpot](https://blog.hubspot.com/marketing/page-load-time-conversion-rates)によると、読み込み時間の最初の5秒はコンバージョン率に大きな影響を与え、それ以降の待ち時間の1秒あたりの影響は–4.4%になります。 これは、ページの読み込み速度がSEO ランキングの主要な要因であるという事実と、サイトパフォーマンスがサイトを維持し、定期的に改善するために重要な要素である理由を示しています。 各パッチリリースにはパフォーマンスの向上が含まれているため、新しいリリースを活用することで成長計画をサポートし、ビジネスの競争力を維持できます。

### 遅延コスト

プラットフォームのアップグレードを遅らせたり延期したりするケースは、多くの場合、直接的なコストに左右されます。 しかし、古いバージョンのソフトウェアを実行するための実際のコストは非常に大きく、ビジネスに長期的な影響を与える可能性があります。

矛盾しているように思えるかもしれませんが、定期的なプラットフォームのアップデートを実行することは、技術的負債が蓄積され、遅延が発生するため、頻繁なアップデートを実行するよりも全体的な労力が少なくて済みます。 Adobeは最近、頻繁にアップグレードを行う頻度が低く、一貫性のない（年間以上）リテール販売店を持つパートナーと連携しました。 アップグレードに対する取り組み方を変革し、12 ヶ月間にわたってAdobeが推奨する定期的なアップグレードパスに従うことで、パートナーはクライアントに対して4週間分に相当する累積開発時間、労力、関連コストを削減することができました。 これらのコストは、ビジネス成長を促進するイニシアチブに振り向けることができます。

更新が定期的に実行されると、変更は増分され、対応するアップグレード作業はこれを反映します。 プラットフォームの更新が長期間にわたって延期されると、プロセスに関与する可能性が高まります。 さらに、[Adobe Commerce Marketplace](https://commercemarketplace.adobe.com//)およびその他のサードパーティの統合から使用する拡張機能も影響を受ける可能性があります。 また、遅延したアップグレードの調査、計画、実行にかかる時間も延長されるので、労力とコストが大幅に削減されます。

プロジェクトをアップグレードする際の労力に影響を与える主な要因には、次のようなものがあります。

| 技術的な複雑さ | AIによる予算策定と戦略 |
|-----------------------------------------------------------|--------------------------------------------------------------|
| カスタマイズの範囲 | 要件の明確化、意思決定の迷い、スコープクリープ |
| 拡張機能の数 | アップグレードの頻度 |
| サードパーティ（OMS、ERP）との統合数 | テスト戦略 |
| ベストプラクティスのコーディング |                                                              |

デジタルコマース分野で成長が続いているため、企業はより迅速かつ頻繁に、予測不可能な方法で進化する必要に迫られています。 顧客の購買行動を把握し、予測できなければ、大規模で実績のある企業であっても、その競争の場は平準化してしまいます。 あらゆる顧客接点をまたいで、パフォーマンスやアップタイムを維持しながら、堅牢でパーソナライズされたエクスペリエンスを提供できる必要があります。 世界の競合他社に一歩先んじるために、イノベーションを無制限に、より迅速に行えなければなりません。 アップグレードすることで、ビジネスの将来性を見据え、動的な顧客ニーズにより的確に対応できるようになります。
