# [!DNL Exceptions]

[!DNL Site-Wide Analysis Tool’s] [!UICONTROL Exceptions] ページには、サイト ログ ファイルのエラーまたは例外が表示されます。 例外は、既知の解決策を持つ場合とそうでない場合がある異常な状態です。

このページに表示される情報には、その日付に例外が発生した[!UICONTROL Last Detected] （UTCの日時）、[!UICONTROL Exception Detail]および[!UICONTROL Count] （発生回数）が含まれます。

## 使用するタイミング

[!UICONTROL Exceptions] ページを使用して、Adobe Commerce プロジェクトのログファイルエラー/例外ログを確認します。 これは、Adobe Commerceのビルドとデプロイのフック、クラウドサービス、Adobe Commerce アプリケーションに関連する問題のトラブルシューティングに役立ちます。

## Adobe Workfrontの利点

* 発生する可能性のある例外とその頻度について説明します。

* 例外ログの問題を追跡し、必要に応じて適切な是正措置を講じてサイトパフォーマンスを向上させます。

## ベストプラクティス

[!DNL Site-Wide Analysis Tool’s] [!UICONTROL Exceptions] ページを監視して、どのような例外が発生するかを確認します。 詳しくは、開発者ドキュメントの「[ ログの表示と管理](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/develop/test/log-locations)」を参照してください。
