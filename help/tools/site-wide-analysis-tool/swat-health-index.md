# SWAT ヘルスインデックスについて

SWAT ダッシュボードから&#x200B;**[!DNL Recommendations Report]**&#x200B;をダウンロードすると、PDFには&#x200B;**概要** セクションに&#x200B;**[!DNL Site Wide Analysis Tool Health Index]** スコアが含まれます。

生成されたRecommendations レポートの![Site Wide Analysis Tool Health Index スコア ](/help/assets/tools/swat-health-index-scroe.png)

SWAT Health Indexは、Adobe Commerceサイトの全体的な健全性を監視および向上させるのに役立ちます。 このスコアはガイダンスツールであり、絶対的な合否メジャーではありません。

## 健康指数とは？

**[!DNL Site Wide Analysis Tool Health Index]**&#x200B;は、自動サイトチェックを0 （最も正常）から1 （最も正常）までの単一スコアに統合します。 チェックには次のものが含まれます。

- セキュリティ評価
- パフォーマンス分析
- ベストプラクティスの評価
- 可用性モニタリング

ヘルスインデックスを使用して、以下を行います。

- サイトの一般的な健全性を迅速に評価する
- 改善点の特定
- 問題に対処しながら進捗を追跡

## ヘルスインデックスの制限

次の重要な制限事項を考慮してください。

- **拘束力がありません**：契約上またはサポート上の結果がスコアに関連付けられていません
- **コンプライアンス保証ではありません**：スコアが高いとは、サイトが完全にリスクフリーであるか、すべての業界標準に準拠していることを示すものではありません
- **すべての変更が反映されない可能性があります**：技術的な制限により、一部の修正（パッチ、設定）がすぐに検出されない場合があります

## ヘルスインデックススコアの使用方法

ヘルスインデックスを次のガイダンスとして使用します。

- **継続的な改善**: スコアの改善に努めますが、スコアが低い場合は失敗と解釈しないでください。
- **作業に優先順位を付ける**：特定のSWAT レコメンデーションを使用して、技術的な作業を導きます。
- **ドキュメントの修正**：問題を修正したがヘルスインデックスが更新されていない場合は、アクションをドキュメント化し、必要に応じてAdobe サポートに問い合わせてください。
- **定期的なレビュー**：定期的にヘルスインデックスを確認して、トレンドを監視し、新しい問題を特定します。
- **全体像**：健全性インデックスを他の監視ツールと組み合わせて、サイトの健全性を包括的に把握します。
- **エキスパートからのアドバイス**：複雑な問題については、Adobe サポートまたは適格な開発者にお問い合わせください。
- **最新情報**：健全なサイトを維持するために、Adobe Commerceの最新情報とベストプラクティスを常に把握します。
