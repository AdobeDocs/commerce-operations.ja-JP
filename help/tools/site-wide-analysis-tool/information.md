# [!DNL Information]

[!DNL Site-Wide Analysis Tool’s] [!UICONTROL Information] ページには、サイトに関する概要情報が表示されます。 このページには、左側のナビゲーションに&#x200B;**[!UICONTROL General Information]**&#x200B;と&#x200B;**Adobe Commerce**&#x200B;の2つの商品領域が表示されています。

[!UICONTROL General Information] エリアには、マーチャント サイトの基本データ、取引先責任者、[!DNL Jira]件の問題（内部使用のみ）、およびレポート チケット セクションが表示されます。

Adobe Commerce領域には、[!UICONTROL Site Details]、[!UICONTROL Products]、[!UICONTROL Project]、[!UICONTROL Integration links]、[!UICONTROL Account]、および[!UICONTROL Service and Components]のセクションが表示されます。

## 使用するタイミング

[!UICONTROL Information] ページを使用すると、上記のすべての詳細を一目で確認できます。

## Adobe Workfrontの利点

* アカウント情報や店舗情報への迅速かつ容易なアクセス：

* ストアの詳細、設定、サービス、コンポーネントのバージョンを1か所で検索して確認できます。

## ベストプラクティス

[!DNL Site-Wide Analysis Tool’s] [!UICONTROL Information] ページには、サイトの概要情報が一覧表示されているので、このページを覚えておいて、ストアまたはアカウントの計画、メンテナンス、サポートのために、情報にすばやくアクセスしてください。
