# ステータス属性

次のステータス情報が、[!DNL Site-Wide Analysis Tool]画面のページの最上位レベルに表示されます。

**[!UICONTROL Environment]**: Adobe Commerce Web サイトの現在の環境を示します。 現在、[!DNL Site-Wide Analysis Tool]画面に表示できる環境は、2つのみです：[!UICONTROL Production]と[!UICONTROL Staging]。 [!UICONTROL Production]環境は、ライブサイトを起動および維持するためのライブ環境です。 [!UICONTROL Staging]環境では、ライブ web サイトで起動する前にサービスがテストされます。

**[!UICONTROL Status]**: Adobe Commerce web サイトのステータスが表示されます。 「[!UICONTROL Live and Stable]」または「[!UICONTROL Dev in Progress]」を指定できます。 「[!UICONTROL Live and Stable]」とは、Web サイトが実行中であることを意味します。 「[!UICONTROL Dev in Progress]」とは、Web サイトが開発中であることを意味します。

**[!UICONTROL Health Index Bar]**: サイト全体の正常性を0から100の範囲で測定します。この値は0から100の範囲で最も悪く、100は完全な正常性です。 アクティブなレコメンデーションの量と優先順位付け係数にもとづいて計算されます。

**[!UICONTROL Download Recommendations Report]**: レコメンデーションレポートは、プロジェクトに適用できるパーソナライズされたレコメンデーションを提供します。 このセクションをクリックすると、PDF レポートをダウンロードできます。
