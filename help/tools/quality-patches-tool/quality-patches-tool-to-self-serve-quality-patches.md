# [!DNL Quality Patches Tool]：品質パッチ用のセルフサービスツール

[!DNL Quality Patches Tool]を使用すると、インストールされているバージョンのAdobe Commerce（オンプレミスおよびクラウドインフラストラクチャの両方）またはMagento Open Sourceで利用できる高品質パッチに関する一般的な情報を適用、元に戻し、表示できます。

このツールは、より迅速なセルフサービス方式の問題解決を提供し、Adobe Commerceで発生する可能性のある問題に対して、Adobe Commerce サポートが提案したパッチを簡単に適用できます。

>[!NOTE]
>
>このツールを使用して、必要に応じて必要な品質修正をケースバイケースで行い、Adobe CommerceとMagento Open Sourceのコードを長期的に管理する方法としてではなく、必要に応じて行う必要があります。 最新バージョンのAdobe CommerceまたはMagento Open Sourceへのアップグレードは、引き続き品質問題の解決に最適な方法であり、優先的に対処する必要があります。

## [!DNL Quality Patches Tool]を取得して使用する

このツールは、コンポーザーパッケージとして使用できます。 Adobe Commerce on cloud infrastructureの場合、パッケージはECE-Tools パッケージに含まれています。

ツールをインストールしたら、利用可能なパッチを確認して、いつでも適用または元に戻すことができます。
