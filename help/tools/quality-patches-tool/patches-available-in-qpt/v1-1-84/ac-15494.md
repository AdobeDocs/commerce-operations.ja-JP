# AC-15494: GraphQL製品クエリがHTML エスケープされた製品名を返す

AC-15494 パッチでは、`products` クエリで、元の文字ではなくHTML エスケープされた特殊文字を含む商品名が返される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはAC-15494です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p5

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

`products` クエリは、元の文字の代わりにHTML エスケープされた特殊文字を含む製品名を返します。

<u>複製する手順</u>:

1. `55" 4K UHD Smart TV`という名前の新しい製品をSKU `testsku`で作成します。
1. 次のGraphQL クエリを送信します。

   ```
   query {
       products(search: "testsku" ) {
           items {
               sku
               name
               description {
                   html
               }
               short_description {
                   html
               }
   
               price_range {
                   maximum_price {
                       final_price {
                           value
                           currency
                       }
                       regular_price {
                           value
                           currency
                       }
                   }
               }
           }
       }
   }
   ```

<u>期待される結果</u>:

`products` クエリは、保存された製品名を元の二重引用符で囲んで返します。

<u>実際の結果</u>:

返される製品名には、元の文字の代わりにHTML エスケープされた二重引用符が含まれています。
