# ACP2E-5263：製品CSVの書き出しが早期に停止し、製品が省略される

ACP2E-5263 パッチは、CSV製品の書き出しがすべての製品を含む前に停止し、不完全なファイルが生成される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5263です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p5

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

すべての製品が含まれる前に、CSVへの製品の書き出しが停止し、不完全なファイルが生成されます。

<u>複製する手順</u>:

1. カタログに複数の商品とセカンダリストアビューが含まれていることを確認します。
2. セカンダリストアビューに画像ラベルが設定されているが、デフォルトのストアビューでは対応する製品画像が使用できない場合は、テスト製品を使用します。
3. 管理画面で、**[!UICONTROL System]** > **[!UICONTROL Data Transfer]** > **[!UICONTROL Export]**&#x200B;に移動します。
4. **[!UICONTROL Entity Type]**&#x200B;を&#x200B;**[!UICONTROL Products]**&#x200B;に設定し、**[!UICONTROL Export File Format]**&#x200B;を&#x200B;**[!UICONTROL CSV]**&#x200B;に設定したままにします。
5. 書き出しフィルターは空白のままにし、属性を除外しないでください。
6. 下にスクロールして、**[!UICONTROL Continue]**&#x200B;をクリックします。
7. 非同期エクスポートが完了するのを待ってから、CSV ファイルをダウンロードして開きます。

<u>期待される結果</u>:

書き出しが完了し、すべての製品を含むCSVが生成されます。

<u>実際の結果</u>:

書き出しは途中で中止されますが、管理者は書き出しファイルの準備ができていることを示し、一部の製品が欠落しているCSVを提供します。
