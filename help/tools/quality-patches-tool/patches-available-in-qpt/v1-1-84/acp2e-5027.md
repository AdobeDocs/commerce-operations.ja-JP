# ACP2E-5027：アプリケーションロックでファイルロックプロバイダーが使用されていると、インデクサーが終了しない

ACP2E-5027 パッチは、`use_application_lock`が有効になっていてファイルロックプロバイダーが設定されている場合に、独自のロックを取得し続けるので、インデクサーが終了しない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5027です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.4 - 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

`use_application_lock`が有効になっていて、ファイルロックプロバイダーが設定されている場合、独自のロックを取得し続けるため、インデクサーは終了しません。

<u>複製する手順</u>:

1. `app/etc/env.php`で、インデクサーのアプリケーションロックを有効にし、ロックプロバイダーをファイルに設定します。

   ```
   'indexer' =>
   array (
     'use_application_lock' => true,
   ),
   'lock' =>
   array (
     'provider' => 'file',
     'config' =>
     array (
       'path' => '<magento_root>/var/lock',
     ),
   )
   ```

1. `catalog_product_category` インデクサーを実行します。

   ```
   bin/magento indexer:reindex catalog_product_category
   ```

<u>期待される結果</u>:

`catalog_product_category`のインデックス再作成が正常に完了しました。

<u>実際の結果</u>:

インデックスの再作成は完了しません。
