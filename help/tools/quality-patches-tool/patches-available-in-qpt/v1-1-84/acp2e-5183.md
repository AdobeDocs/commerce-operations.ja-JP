# ACP2E-5183: PHP 8.5で静的コンテンツのデプロイメントが`@magento_import`で失敗する

ACP2E-5183 パッチは、モジュール `LESS` ファイルが`@magento_import` ディレクティブを使用する場合に、PHP 8.5で静的コンテンツのデプロイメントが失敗し、*配列オフセットとしてnullを使用することは非推奨*&#x200B;になるというエラーが発生する問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5183です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.4 - 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

モジュール `LESS` ファイルで`@magento_import` ディレクティブを使用すると、PHP 8.5で静的コンテンツのデプロイメントが失敗し、エラー&#x200B;*配列オフセットとしてnullを使用すると非推奨*&#x200B;になります。

<u>前提条件</u>:

PHP 8.5がインストールされています。

<u>複製する手順</u>:

1. カスタムメール本文スタイルと`@magento_import` ディレクティブを含む`email-inline.less` ファイルを提供するカスタムモジュールを有効にします。
1. 静的コンテンツと生成ファイルの削除：

   ```
   rm -rf pub/static/frontend/* var/view_preprocessed/* generated/code/*
   ```

1. コンパクトな戦略で静的コンテンツのデプロイメントを実行します。

   ```
   bin/magento setup:static-content:deploy --ansi --no-interaction -f -s compact --jobs 4 --no-html-minify
   ```

<u>期待される結果</u>:

静的コンテンツのデプロイメントが正常に完了し、モジュールが提供する`LESS` ファイルのコンパイル済みCSSを生成します。

<u>実際の結果</u>:

静的コンテンツのデプロイメントは、モジュールが提供する`email-inline.less` ファイルとレポートのコンパイル中に中止します。

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in <magento_root>/vendor/magento/framework/Component/ComponentRegistrar.php on line 71
```
