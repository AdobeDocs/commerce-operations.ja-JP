# ACP2E-5242:GraphQLは、カートへの追加リクエスト時にストア IDをweb サイト IDとして使用します

ACP2E-5242 パッチは、商品をカートに追加する際に製品の可用性を確認すると、web サイトが見つからないことを示すエラーが表示される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5242です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

商品をカートに追加する際に、商品の在庫状況を確認すると、web サイトが見つからないことを示すエラーが表示されます。

<u>複製する手順</u>:

1. Admin パネルにログインします。
1. **管理者** > **[!UICONTROL Stores]** > **設定** > **[!UICONTROL All Stores]**&#x200B;に移動し、**[!UICONTROL Create Store View]**&#x200B;をクリックします。
1. 例えば、「store_2」という名前の2番目のストアビューを作成します。
1. 「Store: store2」 HTTP ヘッダーを使用して、GraphQL リクエストを含む空のゲストカートを作成します。
1. 返されたカート IDを記録します。
1. 「Store: store2」 HTTP ヘッダー、商品SKU、カート IDを使用して、GraphQLリクエストを使用してシンプルな商品をカートに追加します。

<u>期待される結果</u>:

商品は、GraphQL リクエストを介してカートに正常に追加されました。

<u>実際の結果</u>:

GraphQL リクエストが失敗し、「リクエストされたIDを持つweb サイトが見つかりませんでした。 Web サイトを確認して、もう一度やり直してください。」 var/log/exception.logに送信します。
