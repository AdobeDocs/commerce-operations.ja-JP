# ACP2E-5143: GraphQL `route` クエリで、要求されていないCMS ページのコンテンツがレンダリングされる

ACP2E-5143 パッチは、URL ルーティングフィールドのみが要求された場合でも、GraphQL `route` クエリがページビルダーウィジェットや商品リストを含むCMS ページコンテンツ全体をレンダリングし、URL解決が遅くなる問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5143です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7-p9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.4 - 2.4.7-p10

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

URL ルーティングフィールドのみが要求された場合でも、ページビルダーウィジェットや商品リストを含むCMS ページコンテンツ全体がGraphQL `route` クエリでレンダリングされ、URLの解決が遅くなる問題。

<u>前提条件</u>:

Page Builderがインストールされています。

<u>複製する手順</u>:

1. 管理者/**[!UICONTROL Content]** / **[!UICONTROL Elements]** / **[!UICONTROL Pages]**&#x200B;に移動し、**[!UICONTROL Add New Page]**&#x200B;をクリックします。
1. ページの詳細を入力し、**[!UICONTROL Enable Page]**&#x200B;を&#x200B;**[!UICONTROL Yes]**&#x200B;に設定し、**[!UICONTROL Content]** セクションの&#x200B;**[!UICONTROL Edit with Page Builder]**&#x200B;をクリックします。 ページビルダーパネルで「**[!UICONTROL Add Content]**」を展開し、**[!UICONTROL Products]** プレースホルダーをステージにドラッグするか、カタログ製品ウィジェットをページコンテンツに挿入します。
1. 管理画面で、**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]**&#x200B;に移動します。 **[!UICONTROL General]**&#x200B;の下の左側のパネルで、**[!UICONTROL Web]**&#x200B;を選択し、**[!UICONTROL Default Pages]**&#x200B;を展開します。 **[!UICONTROL CMS Home Page]**&#x200B;を新しいページに設定し、**[!UICONTROL Save Config]**&#x200B;をクリックします。
1. 次のGraphQL リクエストを送信します。

   ```
   query ResolveURL($url: String!) {
     route(url: $url) {
       relative_url
       redirect_code
       type
       ... on CmsPage { identifier __typename }
       ... on ProductInterface { uid __typename }
       ... on CategoryInterface { uid __typename }
       __typename
     }
   }
   ```

1. リクエストには次の変数を使用します。

   ```
   { "url": "/" }
   ```

<u>期待される結果</u>:

`route` クエリは、完全な内容をレンダリングせずに、CMS ホームページの要求されたルーティング メタデータと型識別子フィールドを返します。

<u>実際の結果</u>:

1. `route` クエリは、ルーティングメタデータと型識別子フィールドのみが要求されているにもかかわらず、完全なCMS ホームページのコンテンツをレンダリングします。
1. ページビルダーウィジェットで製品コレクションが読み込まれるため、リクエストあたりの応答時間とデータベースクエリの数が増加します。
