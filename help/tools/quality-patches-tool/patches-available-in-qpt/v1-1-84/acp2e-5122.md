# ACP2E-5122：処理されたGraphQL カートのエラーが例外ログに正しく書き込まれない

ACP2E-5122 パッチは、処理されたGraphQL カート要求エラーがアプリケーションエラーとして例外ログに書き込まれる問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.84がインストールされている場合に利用できます。 パッチ IDはACP2E-5122です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p5

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.4 - 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

処理されたGraphQL カートリクエストエラーは、アプリケーションエラーとして例外ログに書き込まれます。

<u>複製する手順</u>:

1. 無効、期限切れ、または既に破棄されたマスクされたカート IDを持つGraphQL `placeOrder` ミューテーションを送信します。例えば、次のミューテーションがあります。

   ```
       mutation {
           placeOrder(input: { cart_id: "test" }) {
               orderV2 {
                   id
                   number
               }
           }
       }
   ```

1. GraphQLの応答を確認します。
1. 買い物かごエラーについては、`var/log/exception.log`を確認してください。

<u>期待される結果</u>:

1. GraphQL リクエストは、*HTTP 500*&#x200B;応答なしで、無効な買い物かごに対して処理されたクライアント対応エラーペイロードを返します。
1. 処理された&#x200B;*GraphQlNoSuchEntityException*&#x200B;は`var/log/exception.log`に書き込まれず、代わりに重要度の低いログチャネルにルーティングされます。

<u>実際の結果</u>:

各リクエストは、処理された例外を`report.ERROR`重要度で`var/log/exception.log`に書き込みます。これにより、繰り返しリクエスト中に無制限のログが増加します。
