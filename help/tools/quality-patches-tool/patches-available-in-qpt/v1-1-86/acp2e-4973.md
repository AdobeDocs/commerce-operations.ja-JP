# ACP2E-4973：店舗内配送から別の配送方法に切り替えると、店舗の住所がカートからクリアされません

ACP2E-4973 パッチは、**[!UICONTROL In-Store Delivery]**&#x200B;から別の配信方法に切り替えても、ストア アドレスがカートからクリアされない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86がインストールされている場合に利用できます。 パッチ IDはACP2E-4973です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p5

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p1 - 2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

**[!UICONTROL In-Store Delivery]**&#x200B;から別の配信方法に切り替えると、ストア アドレスがカートから消去されません。

<u>前提条件</u>:

Inventory management（マルチSource在庫）と実店舗での受け取り：

<u>複製する手順</u>:

1. 管理画面で、**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Sources]**&#x200B;に移動し、**[!UICONTROL Add New Source]**&#x200B;をクリックします。 **[!UICONTROL Name]**&#x200B;と&#x200B;**[!UICONTROL Code]**&#x200B;を入力し、*受け取り場所として使用*&#x200B;を有効にし、**[!UICONTROL Phone]**&#x200B;を&#x200B;**[!UICONTROL Contact Info]**&#x200B;の下に入力し、**[!UICONTROL Country]**、**[!UICONTROL State/Province]**、**[!UICONTROL City]**、**[!UICONTROL Street]**&#x200B;および&#x200B;**[!UICONTROL Postcode]**&#x200B;を&#x200B;**[!UICONTROL Address Data]**&#x200B;の下に入力し、ソースを保存します。
1. **[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stocks]**&#x200B;に移動し、**[!UICONTROL Add New Stock]**&#x200B;をクリックします。 **[!UICONTROL Name]**&#x200B;を入力し、**[!UICONTROL Sales Channels]**&#x200B;の下のweb サイトを選択し、**[!UICONTROL Sources]**&#x200B;の下に新しいソースを割り当て、在庫を保存します。
1. **[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;に移動し、シンプルな製品を作成します。 **[!UICONTROL Sources]** セクションで、**[!UICONTROL Assign Sources]**&#x200B;をクリックし、新しいソースを選択し、正の数量を入力して製品を保存します。
1. **[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL Configuration]** > **[!UICONTROL Sales]** > **[!UICONTROL Delivery Methods]**&#x200B;に移動し、**[!UICONTROL In-Store Delivery]**&#x200B;を展開し、**[!UICONTROL Enabled]**&#x200B;を&#x200B;*Yes*&#x200B;に設定して、**[!UICONTROL Save Config]**&#x200B;をクリックします。
1. GraphQLを登録済みのお客様として使用して、お客様のトークン （`generateCustomerToken`）を生成し、カート ID （`customerCart`）を取得して、商品をカート （`addProductsToCart`）に追加します。
1. `pickup_location_code`のソースコードのみを送信して、カートの配送先住所を受け取り場所に設定します。

   ```
   mutation {
     setShippingAddressesOnCart(input: {
       cart_id: "<cart_id>"
       shipping_addresses: [{ pickup_location_code: "<source_code>" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 買い物かごを&#x200B;**[!UICONTROL Flat Rate]**&#x200B;に切り替えて、応答の`shipping_addresses`を確認します：

   ```
   mutation {
     setShippingMethodsOnCart(input: {
       cart_id: "<cart_id>"
       shipping_methods: [{ carrier_code: "flatrate", method_code: "flatrate" }]
     }) {
       cart { shipping_addresses { pickup_location_code firstname lastname street city postcode } }
     }
   }
   ```

1. 請求先住所（`setBillingAddressOnCart`）と支払い方法（`setPaymentMethodOnCart`、例：`checkmo`）を設定し、新しい配送先住所を設定せずに`placeOrder`を実行します。

<u>期待される結果</u>:

1. **[!UICONTROL Flat Rate]**&#x200B;に切り替えると、`pickup_location_code`と受け取り店舗の住所がカートの配送先住所から削除されます。
1. 有効な宅配便の配送先住所を`setShippingAddressesOnCart`に設定するまで、注文することはできません。

<u>実際の結果</u>:

1. **[!UICONTROL Flat Rate]**&#x200B;に切り替えた後、カートの配送先住所には`pickup_location_code`と受け取り店舗の住所が引き続き含まれます。
1. 注文が行われます。 **[!UICONTROL Sales]** > **[!UICONTROL Orders]**&#x200B;では、注文の配送先住所は受け取り店舗の住所ですが、配達方法は&#x200B;**[!UICONTROL Flat Rate]**&#x200B;です。
