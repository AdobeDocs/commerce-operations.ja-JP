# ACP2E-4191: EAV タイプと属性キャッシュが無効になっている場合、REST API リクエストは無限ループに入ります

ACP2E-4191 パッチは、EAV タイプと属性キャッシュが無効になっている場合に、特定のREST API リクエストが無限ループに入る問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.86がインストールされている場合に利用できます。 パッチ IDはACP2E-4191です。 この問題は、Adobe Commerce 2.4.9で修正されています。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7-p9、2.4.8-p2

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.5 - 2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

EAV タイプと属性キャッシュが無効になっている場合、特定のREST API リクエストは無限ループに入ります。

<u>前提条件</u>:

Adobe Commerce [!DNL B2B]拡張機能。

<u>複製する手順</u>:

1. 顧客アカウントを作成し、ストアフロントにログインします。
1. 商品をカートに追加し、チェックアウトページを開きます。
1. ブラウザーの開発者ツールで、「ネットワーク」タブを開き、`rest/default/V1/carts/mine/estimate-shipping-methods`などのREST リクエストを調べます。
1. EAV タイプと属性キャッシュを無効にします。

   ```
   bin/magento cache:disable eav
   ```

1. チェックアウトページを更新し、同じREST リクエストを調べます。

<u>期待される結果</u>:

1. チェックアウト REST リクエストは、無限ループに入ることなく完了します。

<u>実際の結果</u>:

1. 無限ループがPHP呼び出しスタックサイズまたはメモリ制限に達するため、REST リクエストはHTTP 500 エラーで失敗します。
