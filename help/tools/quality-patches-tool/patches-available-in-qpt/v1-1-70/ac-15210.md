# AC-15210: USPS統合をWeb ツール APIから新しいRESTful USPS APIに移行する

AC-15210 パッチは、Adobe Commerceの既存のUnited States Postal Service （USPS） Web Tools APIの統合を、新しく導入されたUSPS REST APIに移行します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.70がインストールされている場合に利用できます。 パッチ IDはAC-15210です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe CommerceとMagento Open Source（すべてのデプロイメント方法） 2.4.6-p3 - 2.4.8

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

Adobe Commerceは現在、[Web Tools API](https://www.usps.com/business/web-tools-apis/#developers)を使用してUSPSの出荷機能と統合しています。

USPSは、2026年1月25日に従来のWeb Tools APIを廃止する予定です。 これらのAPIは現在、住所の健全性、荷物の追跡、配達確認、受け取りスケジュール、通関フォーム、料金確認、サービス標準、郵便施設情報、小包ロッカーの場所などのサービスをサポートしています。

Adobe Commerce バージョン 2.4.6、2.4.7、および2.4.8では、USPS Web Tools APIを使用して、標準の出荷統合を行います。 退職日以降、新しいUSPS REST APIに移行しない限り、これらの統合は機能しなくなります。

## Solution

2026年1月以降もUSPS統合を引き続き使用するには、バージョン 2.4.6、2.4.7、および2.4.8のAdobe Commerceのお客様は、AC-15210 パッチをインストールする必要があります。

## パッチを適用する

個別のパッチを適用するには、デプロイメント方法に応じて次のリンクを使用します。

* Adobe CommerceまたはMagento Open Source オンプレミス：[!DNL Quality Patches Tool] ガイドの[[!DNL Quality Patches Tool] >使用状況](/help/tools/quality-patches-tool/usage.md)。
* クラウドインフラストラクチャ上のAdobe Commerce:「[&#x200B; アップグレードとパッチ > パッチを適用](https://experienceleague.adobe.com/ja/docs/commerce-on-cloud/user-guide/develop/upgrade/apply-patches)」（Commerce クラウドインフラストラクチャガイド）。

パッチを適用したら、Commerce USPS Shipping Carrier設定を更新して、新しいUSPS APIと統合します。 手順については、*ストアおよび購入エクスペリエンスガイド*&#x200B;の[USPS Web ツールの非推奨](https://experienceleague.adobe.com/ja/docs/commerce-admin/stores-sales/delivery/shipping-carriers/carriers#usps-web-tools-api-deprecation)に関するトピックを参照してください。
