# ACSD-69129: [!DNL REST] デフォルトの基本web サイトを削除し、セカンダリ web サイトをデフォルトとして使用すると、API層の価格の更新が失敗する

ACSD-69129 パッチは、[!DNL REST] APIを介してセカンダリ web サイトのティア価格を更新しようとしたときに、デフォルトの基本web サイトを削除し、セカンダリ web サイトをデフォルトとして使用するとエラーが発生する問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.76がインストールされている場合に利用できます。 パッチ IDはACSD-69129です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.6-p13、2.4.8-p3

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方式） 2.4.5 - 2.4.6-p13、2.4.8 - 2.4.8-p3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

デフォルトの基本web サイトを削除し、セカンダリ web サイトをデフォルトとして使用すると、[!DNL REST] APIを介してセカンダリ web サイトの階層の価格を更新しようとしたときにエラーが発生します。

<u>複製する手順</u>:

1. [!UICONTROL Admin] パネルにログインします。
1. **[!UICONTROL Catalog Price Scope]** = *Web サイト*&#x200B;を設定します。
1. 新しいweb サイト/ストア/ストアビューを作成します。
1. 新しく作成したweb サイトの&#x200B;*デフォルトとして設定*&#x200B;します。
1. キャッシュをクリアします。
1. 新製品を作成します。 2番目のweb サイトにのみ割り当てます。
1. [!DNL REST] API リクエストを送信して、2番目のWeb サイトのティア価格を設定します。
1. 結果は、*200*&#x200B;応答の空の配列である必要があります。
1. [!UICONTROL Admin]で、*メイン Web サイト*&#x200B;を削除します。
1. [!DNL REST] API リクエストを送信して、2番目のWeb サイトのティア価格を設定します。

<u>期待される結果</u>:

* *200*&#x200B;の応答を受信しました。
* 製品のティア価格が更新されます。

<u>実際の結果</u>:

* *無効な属性Web サイト ID = %websiteId。 行ID: SKU = %SKU、Web サイト ID: %websiteId、顧客グループ：%customerGroup、数量：%qty。* 応答でエラーが返されます。
* 製品の階層の価格は更新されません。
