# ACSD-69331: **[!UICONTROL Create Folder]**&#x200B;権限のみの管理者ユーザーに対して、Media Gallery フォルダーの作成が失敗する

ACSD-69331 パッチは、管理者ユーザーが&#x200B;**[!UICONTROL Create Folder]**&#x200B;権限のみが付与された場合にCMS Media Galleryでフォルダーを作成できない問題を修正します。 修正の後、彼らは期待どおりにフォルダを作成することができます。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.76がインストールされている場合に利用できます。 パッチ IDはACSD-69331です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7-p8

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.5 - 2.4.8-p3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

メディアギャラリーで&#x200B;**[!UICONTROL Create Folder]**&#x200B;権限のみを持つ管理者ユーザーは、**[!UICONTROL Delete Folder]**&#x200B;権限も付与されていない限り、フォルダーを作成できません。

<u>複製する手順</u>:

1. Admin パネルにログインします。
1. **[!UICONTROL Dashboard]**&#x200B;および&#x200B;**[!UICONTROL Content]** > **[!UICONTROL Elements]** > **[!UICONTROL Media Gallery]**&#x200B;へのアクセス権を持つ新しい役割を作成し、**[!UICONTROL Create Folder]**&#x200B;権限のみを付与します（**[!UICONTROL Delete Folder]**&#x200B;を付与しないでください）。
1. 新しい管理者ユーザーを作成し、この役割を割り当てます。
1. 新しい管理者ユーザーとしてログインします。
1. **[!UICONTROL Content]** > *[!UICONTROL Media]* > **[!UICONTROL Media Gallery]**&#x200B;に移動します。
1. ディレクトリを選択します（例：`catalog`）。
1. **[!UICONTROL Create Folder]**&#x200B;をクリックします。
1. フォルダー名を入力して確認します。

<u>期待される結果</u>:

* フォルダーの作成は、**[!UICONTROL Create Folder]**&#x200B;権限を持つ管理者ユーザーでのみ機能します。
* フォルダーを作成するために&#x200B;**[!UICONTROL Delete Folder]**&#x200B;権限は必要ありません。

<u>実際の結果</u>:

* ユーザーは&#x200B;**[!UICONTROL Create Folder]**&#x200B;権限のみを持つフォルダーを作成できません。
* フォルダーを作成するには、**[!UICONTROL Delete Folder]**&#x200B;権限の付与が必要です。
