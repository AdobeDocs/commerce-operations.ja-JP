# ACSD-68793：共有カタログの割り当て中に有効な製品が誤って拒否される

ACSD-68793 パッチは、共有カタログの割り当て中に有効な製品が誤って拒否される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.75がインストールされている場合に利用できます。 パッチ IDはACSD-68793です。 この問題は、Adobe Commerce [!DNL B2B] 1.5.3で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce （すべてのデプロイメント方法） [!DNL B2B] 1.5.2-p1

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce （すべてのデプロイメント方式） [!DNL B2B] 1.5.1 - 1.5.2-p3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

[!DNL REST] APIを介した共有カタログの割り当て中に、有効な製品が誤って拒否され、既存のSKUが存在しないことを示すエラーがシステムから返されます。

<u>複製する手順</u>:

1. 複数の商品を作成する。
1. **[!UICONTROL Admin]** サイドバーで、**[!UICONTROL Catalog]** > **[!UICONTROL Shared Catalog]**&#x200B;に移動します。
1. **[!UICONTROL Add Shared Catalog]**&#x200B;をクリックし、共有カタログを作成します。
1. 作成した共有カタログにすべての製品を割り当てます。
1. 既存の製品のSKUのリストを含む[!DNL REST] API リクエストを`/rest/V1/sharedCatalog/3/assignProducts`に送信して、共有カタログに割り当てます。

<u>期待される結果</u>:

正常な応答が返されます。 エラーは、存在しない製品に対してのみ返されます。

<u>実際の結果</u>:

システムがエラーを返します：*リクエストされた製品は存在しません：%sku.* 既存のSKUの場合。
