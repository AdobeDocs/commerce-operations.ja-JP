# ACSD-55334: GraphQLのレスポンスで、翻訳辞書を介してラベルが翻訳されない

ASCD-55334 パッチでは、GraphQLのレスポンスで翻訳ディクショナリを介してラベルが翻訳されない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.43がインストールされている場合に利用できます。 パッチ IDはASCD-55334です。 この問題は、Adobe Commerce 2.4.7で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.4

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.3 - 2.4.6-p3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

ラベルは、GraphQL レスポンスの翻訳辞書を通じて翻訳されません。

<u>複製する手順</u>:

1. 言語パックをインストールします。
1. 次のようなGraphQL リクエストを送信します。

   ```GrapQL
   query {
       products(filter: {}, pageSize: 25, sort: {}) {
           aggregations {
               label
           }
           total_count
       }
   }
   ```

1. 応答を確認します。

<u>期待される結果</u>:

ラベル *[!UICONTROL Category]*&#x200B;が翻訳されています。

<u>実際の結果</u>:

ラベル *[!UICONTROL Category]*&#x200B;は翻訳されていません。
