# ACP2E-4194：不明なフィルター名を持つGraphQL リクエストでPHP例外ログが発生する

ACP2E-4194 パッチは、不明なフィルター名を持つGraphQL リクエストがPHP例外ログを引き起こす問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82がインストールされている場合に利用できます。 パッチ IDはACP2E-4194です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7-p10、2.4.8-p5

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7-p10、2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

不明なフィルター名を持つGraphQL リクエストがPHP例外ログを引き起こす問題。

<u>複製する手順</u>:

不明または不正なフィルター名を持つGraphQL リクエストを送信します。

```
query Test($filter: FindFilterType){ cmsBlocks(identifiers:["home"]) { items { title } } }
```

<u>期待される結果</u>:

リクエストを解析できない場合、リクエストが許可されていない場合、またはリクエストに別の一般的な問題がある場合は、4XX応答コードが返されます。 リクエストを解析して処理できる場合は、*200*&#x200B;応答コードが返されます。

<u>実際の結果</u>:

応答で内部サーバーエラーが返され、`exception.log`に次のエラーが発生しました。

```
report.CRITICAL: LogicException: Config element "FindFilterType" is not declared in GraphQL schema in /var/lib/internal/Magento/Framework/GraphQl/Config.php:57
```
