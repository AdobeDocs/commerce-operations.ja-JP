# ACP2E-4799: GraphQL クエリ `requisition_lists`がページネーションで正しくない`total_count`を返す

ACP2E-4799 パッチは、`requisition_lists` GraphQL クエリが、クエリ条件に一致する要件リストエンティティの合計数ではなく、現在のページの項目数のみを反映する誤った`total_count`値を返す問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82がインストールされている場合に利用できます。 パッチ IDはACP2E-4799です。 この問題は、Adobe Commerce B2B 1.5.4で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） B2B 1.5.2-p4

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） B2B >=1.5.0 &lt;1.5.3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

顧客がページネーション付きの購買リストをクエリする場合、`total_count` フィールドには、一致する購買リストの総数が反映されません。 代わりに、現在のページに対して返されるアイテムの数のみをレポートします。これにより、ページネーションのメタデータが不正確になります。

<u>前提条件</u>:

Adobe Commerce B2Bでは、リクエストリストが有効になっています。

<u>複製する手順</u>:

1. 管理者で、**[!UICONTROL Stores]** > **設定** > **設定**&#x200B;に移動します。
1. **一般**&#x200B;の下の左側のパネルで、**B2B機能**&#x200B;を選択します。
1. **[!UICONTROL Enable Requisition List]**&#x200B;を&#x200B;**[!UICONTROL Yes]**&#x200B;に設定し、**[!UICONTROL Save Config]**&#x200B;を選択します。
1. 顧客としてストアフロントにログインします。
1. **[!UICONTROL My Requisition Lists]**&#x200B;を選択し、6つの購買リストを作成します。
1. 顧客が正確に6つの購買リストを持ち、各リスト名に`ABC`が含まれていることを確認し、6つのリストがすべてフィルターされたクエリと一致するようにします。
1. `pageSize`が2に、`currentPage`が1に設定された次のGraphQL クエリを実行します。

   ```graphql
   query {
     customer {
       requisition_lists(
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```

1. 次のGraphQL クエリを実行します。

   ```graphql
   query {
     customer {
       requisition_lists(
         filter: { name: { match: "%ABC%" } }
         pageSize: 2
         currentPage: 1
       ) {
         items {
           uid
           name
         }
         total_count
         page_info {
           current_page
           page_size
           total_pages
         }
       }
     }
   }
   ```


<u>期待される結果</u>:

* `requisition_lists` クエリは、`pageSize`と`currentPage`とは独立して、顧客が所有する購買リストの合計数に等しい`total_count`を返します。
* ページネーション データは、完全に一致する結果セットと一致したままになります。

<u>実際の結果</u>:

`total_count`は、現在のページの項目数のみを返します。例えば、6個ではなく2個です。
