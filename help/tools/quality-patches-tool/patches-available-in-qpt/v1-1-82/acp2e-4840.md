# ACP2E-4840:GraphQL商品クエリで、カスタム在庫在庫の在庫商品に関するnull数量が返される

ACP2E-4840 パッチは、在庫があり、カスタム在庫在庫で販売可能な商品について、商品GraphQL クエリの数量フィールドでnullが返される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.82がインストールされている場合に利用できます。 パッチ IDはACP2E-4840です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p4

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8 - 2.4.8-p5

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

商品GraphQL クエリの数量フィールドは、在庫があり、カスタム在庫在庫で販売可能な商品についてnullを返します。

<u>前提条件</u>:

MSIが有効になっています。

<u>複製する手順</u>:

1. 新しいソースを作成します。
1. 管理者サイドバーで、**[!UICONTROL Stores]** > **[!UICONTROL Inventory]** > **[!UICONTROL Stock]**&#x200B;に移動します。
1. **[!UICONTROL Add New Stock]**&#x200B;をクリックします。
1. **[!UICONTROL Sales Channels]**&#x200B;を展開し、在庫が利用可能な&#x200B;**[!UICONTROL Websites]**&#x200B;を選択します。
1. **[!UICONTROL Sources]**&#x200B;を展開し、**[!UICONTROL Assign Sources]**&#x200B;をクリックし、割り当てるソースを選択して、**[!UICONTROL Done]**&#x200B;をクリックします。
1. 管理サイドバーで、**[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;に移動し、既存の製品を編集モードで開きます。
1. **[!UICONTROL Sources]** セクションで、カスタムソースを割り当て、**[!UICONTROL Source Item Status]**&#x200B;を&#x200B;**[!UICONTROL In Stock]**&#x200B;に設定し、**[!UICONTROL Qty]**&#x200B;に0以外の値を入力して、製品を保存します。
1. **[!UICONTROL Catalog]** > **[!UICONTROL Products]**&#x200B;で、製品がカスタム在庫に割り当てられたweb サイトに対してゼロ以外の&#x200B;**[!UICONTROL Salable Quantity]**&#x200B;を表示していることを確認します。
1. カスタム在庫を使用するweb サイトに割り当てられたストアビューに対して、そのSKUに対して次の`products` [!DNL GraphQL] クエリを実行します。

   ```
   query {
     products(filter: { sku: { in: ["product_dynamic_1"] } }) {
       items {
         sku
         name
         stock_status
         quantity
         max_sale_qty
       }
     }
   }
   ```

1. 応答を観察する：

   ```
   {
     "data": {
       "products": {
         "items": [
           {
             "sku": "product_dynamic_1",
             "name": "Simple Product 1",
             "stock_status": "IN_STOCK",
             "quantity": null,
             "max_sale_qty": 10000
           }
         ]
       }
     }
   }
   ```

<u>期待される結果</u>:

GraphQLの応答では、在庫があり、現在の店舗/web サイトで販売可能な商品について、null以外の数量の値が返されます。

<u>実際の結果</u>:

ストアがカスタム MSI在庫を使用する場合、GraphQLの応答は`quantity = null`を返しますが、`stock_status` = `IN_STOCK`は在庫があり、管理画面で販売可能な商品に対して返されます。
