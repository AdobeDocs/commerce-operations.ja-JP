# AC-18096: Sales GraphQLの日付フィールドが正しくないローカライズされた書式を返す

AC-18096 パッチでは、Sales GraphQLの日付フィールドで、以前のリリースとは異なる形式で日付が返される問題を修正します。日付の形式をスラッシュ区切りの`/`からダッシュ区切りの`-`に戻します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはAC-18096です。 この問題は、Adobe Commerce 2.4.9で修正されています。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） >2.4.8 &lt;=2.4.9-p1

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

Sales GraphQLの日付フィールドは、Adobe Commerce 2.4.8で使用されているダッシュ区切り形式`(Y-m-d H:i:s)`ではなく、スラッシュ区切り形式`(d/m/Y H:i:s)`で日付と時刻の値を返します

<u>前提条件</u>:

- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Timezone]**: *ヨーロッパ/パリ*
- **[!UICONTROL General]** > **[!UICONTROL Locale Options]** > **[!UICONTROL Locale]**: *フランス語（フランス）*

<u>複製する手順</u>:

1. 注文の作成。
1. GraphQLを使用して注文日の詳細を取得します。

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>期待される結果</u>:

- フィールドは`Y-m-d H:i:s`の値を返し、バージョン 2.4.8の出力と一致します。

<u>実際の結果</u>:

- フィールドは、`2026-08-27 14:12:55`のように`Y-m-d H:i:s`ではなく、`27/08/2026 14:12:55`など、`d/m/Y H:i:s`の値を返します。
