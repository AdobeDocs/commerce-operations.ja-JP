# ACP2E-4998: SKUが見つからない場合、有効な製品の一括価格更新が行われません

ACP2E-4998 パッチは、ペイロード内の1つのSKUが存在しない場合に`POST /V1/products/tier-prices` REST API リクエストが完全に失敗し、有効なSKUが更新されない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはACP2E-4998です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.7 - p10

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） >= 2.4.7 &lt; 2.4.8

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

ペイロード内の1つのSKUが存在しない場合、`POST /V1/products/tier-prices` REST API リクエストは完全に失敗し、有効なSKUが更新されません。

<u>複製する手順</u>:

1. 既存の製品SKU （`product_dynamic_1`など）と、カタログに存在しないSKU （`product_dynamic_001`など）を1つ特定します。
1. 同じペイロード内の両方のSKUを含む`/rest/V1/products/tier-prices`にPOST リクエストを送信します。

   ```json
   {
     "prices": [
       {
         "sku": "product_dynamic_1",
         "customer_group": "General",
         "quantity": 5,
         "price": 31.99,
         "price_type": "fixed",
         "website_id": 0
       },
       {
         "sku": "product_dynamic_001",
         "customer_group": "General",
         "quantity": 5,
         "price": 54.49,
         "price_type": "fixed",
         "website_id": 0
       }
     ]
   }
   ```

<u>期待される結果</u>:

1. 階層価格は、既存のSKUに対して保存されます。
1. 応答は、欠落しているSKUをアイテムレベルのエラーとして報告します。

<u>実際の結果</u>:

1. リクエストが失敗し、エラーが発生しました。*SKU &quot;%1&quot;を持つ製品は存在しません。* `product_dynamic_001`の。
1. 既存のSKUの階層価格は保存されません。
