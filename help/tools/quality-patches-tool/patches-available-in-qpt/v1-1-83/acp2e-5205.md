# ACP2E-5205：大きなカタログを使用すると、Adminでカテゴリの読み込みが遅くなり、タイムアウトが発生する

ACP2E-5205 パッチは、多数のカテゴリと製品が関与している場合にカテゴリの読み込みに時間がかかったり、タイムアウトの問題が発生したりする問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはACP2E-5205です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p3

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） >= 2.4.8 &lt; 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

カテゴリの読み込みに時間がかかるか、多数のカテゴリや製品が含まれている場合にタイムアウトの問題が発生します。

<u>複製する手順</u>:

1. *2500* **[!UICONTROL Categories]**&#x200B;と少なくとも&#x200B;*10000* **[!UICONTROL Products]**&#x200B;を作成します。
   1. `setup/performance-toolkit`のコピーを作成し、`./var`に配置してプロファイルを編集できるようにします。
   1. `small.xml` プロファイルを編集し、**[!UICONTROL Categories]** = *2500*&#x200B;および&#x200B;**[!UICONTROL Products]** = *250000*&#x200B;と設定します。
   1. `bin/magento setup:performance:generate-fixtures var/setup/performance-toolkit/profiles/ce/small.xml`を実行します。
1. 製品とカテゴリを作成したら、それらがすべてアンカーであることを確認し、クエリを実行します。

   ```
   UPDATE catalog_category_entity_int set value = 1 where attribute_id = (select attribute_id from eav_attribute where attribute_code = 'is_anchor');
   ```

1. 管理メニューに移動し、カテゴリのより深い構造を持っていることを確認してから、カテゴリ 2をカテゴリ 1のツリーに深く移動します。
1. 再インデックス：

<u>期待される結果</u>:

すべてのカテゴリは、最初のキャッシュされていない試行から開き、わずか数秒で開きます。

<u>実際の結果</u>:

開封には1分以上かかります。
