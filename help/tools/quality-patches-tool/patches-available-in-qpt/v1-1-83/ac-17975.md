# AC-17975: PHP 8.5の互換性の問題は、CLI コマンド、カテゴリ編集、デザイン設定、および顧客ログインに影響します

AC-17975 パッチでは、PHP 8.5を使用すると、Adobe Commerce 2.4.9でCLI コマンド、カテゴリ編集、デザイン設定、AJAX カスタマーログインが失敗する問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはAC-17975です。 この問題は、Adobe Commerce 2.4.9-p1および2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.9

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

ADOBE COMMERCE 2.4.9がPHP 8.5で実行されている場合、CLI コマンド、カテゴリ編集、デザイン設定、AJAX カスタマーログインが失敗します。

<u>前提条件</u>:

PHP 8.5がインストールされています。

<u>複製する手順</u>:

1. 次のCLI コマンドを実行します。

   ```
   bin/magento --version
   ```

1. ストアフロントでは、チェックアウトを完了し、チェックアウト中にログインします。また、顧客のCAPTCHAでログインとチェックアウトが有効になります。
1. 管理者で、カテゴリ属性が`frontend_input`に`null`に設定されている場合にカテゴリを開きます。
1. 管理者で、**[!UICONTROL Content]** > **[!UICONTROL Design]** > **[!UICONTROL Configuration]**&#x200B;に移動し、**[!UICONTROL Action]**&#x200B;列の&#x200B;**[!UICONTROL Edit]**&#x200B;をクリックしてストアビューを表示します。


<u>期待される結果</u>:

すべての操作が正常に完了しました。


<u>実際の結果</u>:

操作は、次のようなエラーで失敗します。

```
Exception #0 (Exception): Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead
/var/www/html/vendor/magento/framework/App/Config/ScopeCodeResolver.php on line 62
```

```
report.CRITICAL: Exception: Deprecated Functionality: Using null as the key parameter for array_key_exists() ... in module-captcha/Helper/Data.php on line 92
```

```
There is an error in vendor/magento/framework/Setup/Mvc/MvcApplication.php at line: 170
Undefined constant "Magento\Framework\Setup\Mvc\GLOB_BRACE"
```

```
Deprecated Functionality: Using null as an array offset is deprecated, use an empty string instead in
var/www/html/app/code/Magento/Catalog/Model/Category/DataProvider.php on line 41
```
