# AC-18128：英語以外のロケールで、GraphQLの注文日とコメントのタイムスタンプが正しくない

AC-18128 パッチでは、GraphQLから返される注文日と注文コメントのタイムスタンプが、英語以外のロケール設定で誤ったカレンダー日付を表示する問題が修正されました。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはAC-18128です。 この問題は、Adobe Commerce 2.4.8で修正されています。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方式） >=2.4.8 &lt;2.4.8-p6

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

GraphQLから返される注文日と注文コメントのタイムスタンプは、英語以外のロケール設定で誤ったカレンダー日付を表示する可能性があります。

<u>複製する手順</u>:

1. 管理パネルで、**[!UICONTROL Stores]** > **[!UICONTROL Configuration]** > **[!UICONTROL General]** > **[!UICONTROL Locale Options]**&#x200B;に移動します。 **[!UICONTROL Timezone]**&#x200B;を&#x200B;*ヨーロッパ/パリ*&#x200B;に設定します。 **[!UICONTROL Locale]**&#x200B;を&#x200B;*フランス語（フランス）*&#x200B;に設定します。 設定を保存します。
1. ストアフロントで注文。
1. 次のCustomer Orders GraphQL クエリを実行します。

   ```graphql
   query getOrders {
       customer {
           orders {
               items {
                   orderDateOK: created_at
                   orderDateFAIL: order_date
               }
           }
       }
   }
   ```

<u>期待される結果</u>:

GraphQLの応答の注文日とコメントのタイムスタンプは、店舗のロケールに関係なく、正しいカレンダー日を反映します。

<u>実際の結果</u>:

`fr_FR`や`de_DE`などの`en_US`以外のロケールの場合、`order_date`は日付解析の問題により、間違ったカレンダー日付を表示します。
