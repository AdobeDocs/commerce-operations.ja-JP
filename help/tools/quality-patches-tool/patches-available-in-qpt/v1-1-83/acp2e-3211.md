# ACP2E-3211：並列カート追加要求により、同じSKUに対して別々の項目が作成される

ACP2E-3211 パッチは、ストアフロントで同じ商品を同時にカートに追加すると、同じSKUのカート内に同じ商品を単一の商品に組み合わせるのではなく、別の商品が作成される問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはACP2E-3211です。 この問題は、Adobe Commerce 2.4.8で修正されています。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.5-p7

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.5 - 2.4.7-p10

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

ストアフロントで同じ商品を同時にカートに追加すると、単一の商品に組み合わせるのではなく、同じSKUのカート内に別々の商品が作成されます。

<u>複製する手順</u>:

1. 新製品を作成します。
2. 新しい顧客アカウントを作成し、ログインします。
3. 製品ページに移動し、**開発ツール** > **ネットワーク**&#x200B;を開き、製品をカートに追加します。
4. 商品をカートに追加するcurl （bash）リクエストをコピーします。
5. コピーしたcurl クエリを2つのコンソールインスタンスで使用して、できるだけ早く2回トリガーします。

<u>期待される結果</u>:

- 商品は、1つの買い物かごアイテムとして`qty=2`と共に追加されます。

<u>実際の結果</u>:

- 商品は2つの個別のカート商品として追加されます。
