# ACP2E-4639:Adobe Commerce GraphQL スキーマで要求リストのアイテムの種類のスペルが間違っている

ACP2E-4639 パッチは、GraphQL スキーマで購買依頼リストの項目タイプのスペルが間違っている問題を修正します。 新しい`requisition_list_items` フィールドは正しいスペルの`RequisitionListItems` タイプを返しますが、古い`items` フィールドと`RequistionListItems` タイプは引き続き使用できますが、非推奨です。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはACP2E-4639です。 この問題は、Adobe Commerce B2B 1.5.3で修正されています。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） B2B 1.5.2 - p1

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） B2B >= 1.3.4 &lt; 1.5.3

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

購買リストのアイテムの種類は、GraphQL スキーマで`RequistionListItems`とスペルが間違っています。 古い`items` フィールドと`RequistionListItems` タイプは引き続き使用できますが、非推奨です。

<u>前提条件</u>:

B2B拡張機能を備えたAdobe Commerce。

<u>複製する手順</u>:

1. 次のGraphQL イントロスペクションクエリを送信します。

   ```
   {
     __type(name: "RequisitionList") {
       fields(includeDeprecated: true) {
         name
         isDeprecated
         type {
           name
         }
       }
     }
   }
   ```

1. 応答で、`items` フィールドが返すタイプを確認します。

<u>期待される結果</u>:

1. `requisition_list_items` フィールドは、正しいスペルの`RequisitionListItems` タイプを返します。
1. `items` フィールドと`RequistionListItems` タイプは引き続き使用でき、非推奨としてマークされます。

<u>実際の結果</u>:

`items` フィールドはスペルが間違っている`RequistionListItems` タイプを返し、正しいスペルの`RequisitionListItems` タイプを返すフィールドはありません。
