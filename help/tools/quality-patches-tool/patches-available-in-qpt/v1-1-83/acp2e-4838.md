# ACP2E-4838：制限付き管理者ユーザーが、許可されたweb サイトから顧客を削除できない

ACP2E-4838 パッチは、権限が制限された管理者ユーザーが顧客グリッドから顧客を削除できない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.83がインストールされている場合に利用できます。 パッチ IDはACP2E-4838です。 この問題は、Adobe Commerce 2.4.10で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p3

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） >=2.4.4 &lt;2.4.10

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ &#x200B;](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html?lang=ja)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

制限された権限を持つ管理者ユーザーは、顧客グリッドから顧客を削除できません。

<u>複製する手順</u>:

1. 管理パネルで、**[!UICONTROL Stores]** > **[!UICONTROL Settings]** > **[!UICONTROL All Stores]**&#x200B;に移動します。 **[!UICONTROL Main Website]**&#x200B;にデフォルトの&#x200B;**[!UICONTROL Main Website Store]**&#x200B;と&#x200B;**[!UICONTROL Default Store View]**&#x200B;があることを確認します。 以下を作成します。
   * ストア：**[!UICONTROL Create Store]**&#x200B;をクリックし、**[!UICONTROL Web Site]**&#x200B;を&#x200B;**[!UICONTROL Main Website]**&#x200B;に設定し、**[!UICONTROL Name]**&#x200B;に`Group A`を入力し、一意の&#x200B;**[!UICONTROL Code]**&#x200B;を入力して、**[!UICONTROL Save Store]**&#x200B;をクリックします。
   * ストアビュー：**[!UICONTROL Create Store View]**&#x200B;をクリックし、**[!UICONTROL Store]**&#x200B;を&#x200B;**[!UICONTROL Group A]**&#x200B;に設定し、**[!UICONTROL Name]**&#x200B;に`Store View A`を入力し、一意の&#x200B;**[!UICONTROL Code]**&#x200B;を入力し、**[!UICONTROL Status]**&#x200B;を&#x200B;**[!UICONTROL Enabled]**&#x200B;に設定し、**[!UICONTROL Save Store View]**&#x200B;をクリックします。
1. **[!UICONTROL Default Store View]**&#x200B;を通じて顧客アカウントを作成し、顧客が&#x200B;**[!UICONTROL Main Website]**&#x200B;と&#x200B;**[!UICONTROL Default Store View]**&#x200B;に属するようにします。
1. **[!UICONTROL System]** > **[!UICONTROL Permissions]** > **[!UICONTROL User Roles]**&#x200B;に移動し、**[!UICONTROL Add New Role]**&#x200B;をクリックします。
1. **[!UICONTROL Role Resources]**&#x200B;で、**[!UICONTROL Customers]** > **[!UICONTROL All Customers]**&#x200B;とその権限&#x200B;**[!UICONTROL Delete]**&#x200B;を選択します。
1. **[!UICONTROL Role Scopes]**&#x200B;で、**[!UICONTROL Main Website]**&#x200B;の&#x200B;**[!UICONTROL Custom]**&#x200B;を選択し、`Group A`のみを許可します。ただし、**[!UICONTROL Main Website Store]**&#x200B;は選択されていません。
1. 管理者ユーザーを作成し、制限された役割に割り当てます。
1. 制限付きユーザーとしてAdmin パネルにログインします。
1. **[!UICONTROL Customers]** > **[!UICONTROL All Customers]**&#x200B;に移動します。
1. 顧客を選択し、**[!UICONTROL Actions]** ドロップダウンメニューから&#x200B;**[!UICONTROL Delete]**&#x200B;を選択します。

<u>期待される結果</u>:

制限付き管理者ユーザーは、お客様のweb サイトが役割スコープ内にあるため、お客様を開いて削除できます。ただし、お客様は役割スコープ外のストアビューで作成されています。

<u>実際の結果</u>:

お客様は削除されず、管理者に次のエラーメッセージが表示されます。*この項目を表示するには、さらに権限が必要です。*
