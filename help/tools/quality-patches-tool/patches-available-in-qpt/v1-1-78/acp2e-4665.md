# ACP2E-4665：製品ギャラリー内のビデオを含む設定可能な製品の子製品が、REST APIで要求されたときに表示されない

ACP2E-4665 パッチは、ビデオが製品ギャラリーに含まれる場合に、設定可能な製品の子製品がREST APIによって返されない問題を修正します。 このパッチは、[[!DNL Quality Patches Tool (QPT)]](/help/tools/quality-patches-tool/quality-patches-tool-to-self-serve-quality-patches.md) 1.1.78がインストールされている場合に利用できます。 パッチ IDはACP2E-4665です。 この問題は、Adobe Commerce 2.4.9で修正される予定です。

## 影響を受ける製品とバージョン

**パッチはAdobe Commerceのバージョン**&#x200B;用に作成されました

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8-p3

**Adobe Commerceのバージョンとの互換性：**

* Adobe Commerce（すべてのデプロイメント方法） 2.4.8 - 2.4.8-p4

>[!NOTE]
>
>このパッチは、新しい[!DNL Quality Patches Tool] リリースを含む他のバージョンに適用される可能性があります。 パッチがAdobe Commerceのバージョンと互換性があるかどうかを確認するには、`magento/quality-patches` パッケージを最新バージョンに更新し、[[!DNL Quality Patches Tool]：パッチの検索ページ ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)で互換性を確認します。 パッチ IDを検索キーワードとして使用して、パッチを検索します。

## イシュー

製品ギャラリーにビデオが存在する場合、REST APIは設定可能な製品の子製品を返しません。

<u>複製する手順</u>:

1. 設定可能な製品の子製品にビデオを追加します。
1. 次のREST API エンドポイントにリクエストを送信します。
   `rest/v1/configurable-products/<PARENT_CONFIGURABLE_PRODUCT_SKU>/children`.

<u>期待される結果</u>:

REST APIは、製品に関する情報を返します。

<u>実際の結果</u>:

REST APIは次のエラーを返します。

```
Error: Call to a member function getVideoProvider() on null in vendor/magento/module-product-video/Model/Product/Attribute/Media/ExternalVideoEntryConverter.php:87" exception.
```
