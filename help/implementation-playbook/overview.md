# CMS実装

このプレイブックの目的は、Adobe Commerceの一般的な実装の全体像を提供することです。

Adobe Commerceプロジェクトを成功させるためには、プロジェクトスコープの策定から統合、導入、継続的なサポートに至るまで、さまざまな手法やベストプラクティスを考慮する必要があります。

さらに、次のプロセスと考慮事項は、あらゆる種類のAdobe Commerce プロジェクトに適用されます。

- 小規模、中規模、大規模の導入
- B2C、B2B、B2B2Cのビジネスモデル
- モノリシックまたはヘッドレスアーキテクチャ
- シングルマーケットロールアウトまたはマルチマーケットロールアウト
- ミドルウェアの有無にかかわらず拡張可能な統合

このプレイブックが、e コマースプロジェクトに普段関わっているさまざまな関係者に、次のようなインサイトとガイダンスを提供することを願っています。

- コマース展開に何が必要かをしっかりと把握している必要があるCEOや一般管理職
- CMOとデジタルマネージャー：プラットフォーム自体でビジネスユーザーと協力する
- テクノロジープロジェクトの導入のあらゆる段階に深く関わるCTOやテクニカルマネージャー
- コマースプロジェクトの取り組みを主導する、あらゆるプロジェクトマネージャーとプロジェクトチャンピオンが、関連するあらゆる情報を手元に置く必要があります

IT プロジェクトの成果は、コードを開発、カスタマイズ、統合、保守する部門（通常はソリューションパートナー）の経験や専門知識に大きく左右されますが、あらゆる関係者がAdobe Commerce導入のベストプラクティスに慣れることが重要です。
